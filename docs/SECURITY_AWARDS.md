## 🏆 Приоритет 1 — бесплатные демо-площадки security-инструментов (самое ценное)

| Площадка | Что даёт | Платность | Статус |
|---|---|---|---|
| **Black Hat Arsenal** | демо open-source security-инструмента на главной мировой ИБ-конференции, обзорный пост на blackhat.com, бесплатный билет | **бесплатно** | Call for Tools перед каждым событием. Europe 2026 (open 24.04 → closed 19.07, notify 24.08), India 2026 (deadline 03.07) — закрыты. **Ждать: Asia 2027 (call открывается ~осень 2026), USA 2027** |
| **DEF CON Demo Labs** | демо на DEF CON (Лас-Вегас) | бесплатно | DEF CON 34 = 2026. Call открывается весной-летом перед событием |
| **SecTor (Black Hat Канада) Arsenal** | как Arsenal, но Канада | бесплатно | закрыт на 2026, следующий цикл 2027 |

**Почему это #1 для GSC:** Arsenal даёт именно то, чего не хватает для продажи —
независимое признание в security-комьюнити + visibility у покупателей (PT, Snyk,
Checkmarx — все ходят на Black Hat). И это бесплатно.

## Рекомендация

**Порядок действий для GSC:**
1. **Black Hat Arsenal (Asia 2027 / USA 2027)** — подать как только откроется call for
   tools. Это главный бесплатный рычаг traction. Требуется: описание инструмента +
   рабочее демо. У GSC всё есть.
2. **GitHub Accelerator** — мониторить набор когорты (грант $40K).
3. **Awards 2027** — подать на Cybersecurity Excellence / SC Awards, когда откроются,
   если к тому моменту будет бюджет или скидка early-bird.
4. **PHDays / Standoff** — если нужно RF-присутствие (контакт с PT-экосистемой).

## Что нужно верифицировать перед подачей (не из памяти)

- Точные даты call-for-tools Black Hat Asia 2027 (открывается на blackhat.com/arsenal).
- Условия GitHub Accelerator текущей когорты (github.com/accelerator).
- Early-bird цены awards 2027.
