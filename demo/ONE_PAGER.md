# GSC — Git Security Checker

> **Первый в мире самообучающийся сканер с автодоказательством уязвимостей.**
> Не «вот список находок», а «вот доказанные уязвимости + авто-PR с исправлением».

---

## Проблема

Snyk, Semgrep, SonarQube находят сотни находок. 60–80% — ложные срабатывания.
Разработчики игнорируют алерты. AppSec-инженеры тонут в триаже.

## Решение GSC

Полный цикл за один запуск:

```
detect → prove → fix → verify → heal → predict → learn
```

| Этап | Что делает GSC | Конкуренты |
|------|---------------|------------|
| **Detect** | 29 детекторов (SAST+SCA+Secrets+IaC+DAST) | ✅ есть у всех |
| **Prove** | PoC Auto-Generation — живой эксплойт | ❌ нет ни у кого |
| **Fix** | Авто-патч с фиксом | ⚠️ Semgrep (только паттерн) |
| **Verify** | Proof-of-Fix: до/после верификация | ❌ нет ни у кого |
| **Heal** | Self-Healing CI — авто-PR | ❌ нет ни у кого |
| **Predict** | Forecasting — где появятся уязвимости | ❌ нет ни у кого |
| **Learn** | Federated Self-Learning (DP) | ❌ нет ни у кого |

## Ключевое отличие

**Snyk:** «439 находок, 71 ложное — разбирайтесь»
**GSC:** «4 доказанные уязвимости, авто-PR с исправлением»

PoC-верификация убирает FP: показываются только те уязвимости,
для которых сгенерирован и проверен эксплойт.

## Как попробовать

```
# 15 минут на подключение:
pip install gsc-scanner
gsc scan ./my-repo --ci --json

# Результат: только доказанные уязвимости
```

## Пилотное предложение

Бесплатно просканируем 3 ваших репозитория.
Покажем только доказанные уязвимости (с PoC).
Откроем авто-PR с исправлениями.
От вас — 15 минут на подключение и честный отзыв.
