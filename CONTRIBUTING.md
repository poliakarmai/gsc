# Contributing to GSC

GSC — продукт с закрытым движком (BSL 1.1). Этот репозиторий — публичная витрина.

## Статус кода

Ядро GSC (детекторы, PoC/PoF-движок, калибровочная сеть, LLM-слой) поставляется
как закрытый Docker-образ под **Business Source License 1.1 (BSL 1.1)** и не
публикуется в этом репозитории. Здесь — только Action, документация и маркетинг.

## Как поучаствовать

- **Баги / фича-реквесты / сотрудничество** — откройте Issue или напишите автору.
- **Демо / пилот / приобретение** — свяжитесь напрямую.

## Лицензия

Код этого репозитория (Action + документация) — под [Apache License 2.0](LICENSE).
Движок (Docker-образ) — под BSL 1.1. Подробнее — [README.md](README.md).
