# Contributing to GSC

GSC — коммерческий продукт с закрытым ядром. Этот репозиторий — публичная витрина.

## Статус кода

Ядро GSC (детекторы, PoC/PoF-движок, калибровочная сеть, LLM-слой) — **проприетарное
(closed-source)** и не публикуется здесь. В этом репозитории — только витрина и
маркетинговые материалы.

## Как поучаствовать

- **Баги / фича-реквесты / сотрудничество** — откройте Issue или напишите автору.
- **Демо / пилот / приобретение** — свяжитесь напрямую.

## Лицензия

Весь опубликованный код — под проприетарной лицензией [LICENSE](LICENSE).
См. [README.md](README.md).
